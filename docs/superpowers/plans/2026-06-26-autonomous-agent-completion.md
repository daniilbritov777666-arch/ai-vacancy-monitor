# Autonomous Freelance Agent Completion Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** довести локального freelance-agent до проверяемого состояния, где он сам находит разовые IT-заказы, откликается, ведет переписку, готовит результат, обрабатывает правки и доводит заказ до оплаты через доступные платежные каналы.

**Architecture:** агент остается локальным macOS LaunchAgent с JSON-состоянием в `orders/`, Telegram-уведомлениями, OpenAI-compatible LLM, Freelancehunt API и email-каналом для публичных источников. Автономность должна проверяться не словами, а состояниями заказов, логами отправки, API-аудитом, QA-отчетами и платежными артефактами.

**Tech Stack:** Python, pytest, LaunchAgent, Freelancehunt API, SMTP/IMAP, OpenAI-compatible `/v1`, local JSON store, optional Docker/Lima execution verifier.
